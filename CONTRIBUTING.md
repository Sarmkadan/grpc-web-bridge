# Contributing to grpc-web-bridge

First off, thank you for considering contributing to grpc-web-bridge!

## Getting Started

1. **Fork** the repository on GitHub.
2. **Clone** your fork locally.
3. **Create a branch** for your edits.
4. **Make your changes**.
5. **Run tests** to ensure everything works correctly.
6. **Submit a Pull Request**.

## Development Requirements

- **.NET 10.0 SDK**

## Code Style

- Please follow the existing coding conventions found in the project.
- Provide **XML docs** for all public classes and methods.
- **Keep author headers** intact; DO NOT remove them from existing files.

## Reporting Issues

If you find a bug or have a feature request, please use **GitHub Issues**. 
When reporting an issue, please include detailed reproduction steps.
